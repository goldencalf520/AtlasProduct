## 正文

```
做的东西一多，链接就散了。
部署地址在收藏夹，代码在 GitHub，截图在相册。
想给别人看的时候，得翻半天。

于是做了个 Atlas 产品管理器：
把部署链接和 GitHub 仓库一贴，标题、简介、图标、Star 自动填好。

现在库里收了 7 个常看的开源项目，Star 加起来 72 万+。
卡片、列表、表格三种视图，搜索、标签、状态筛选都有。

它解决 4 件事：
1. 作品太散：一条链接收一个产品，按分类归档
2. 手填太烦：粘贴链接，点「自动抓取」，信息自动回填
3. 数据会旧：填了 GitHub 仓库，保存后自动同步 Star、Fork、语言和最近提交
4. 展示单一：卡片看视觉，列表看信息，表格看数据

怎么用：
1. 打开站点，点「添加产品」
2. 粘贴线上部署链接，点「自动抓取」
3. 有仓库就补 GitHub 地址，保存时自动同步
4. 回首页切视图、搜索、筛选

部署：
Trae → 插件市场 → 一键部署 → 使用
按向导发布，拿到 traesite.cn 的公网链接，手机也能打开。

入口：
https://37lgscscgjx6knweewv.traesite.cn/

不用配数据库，一份 JSON 就是全部数据。
演示站的数据存在临时目录，服务重启会回到 7 个样例；想长期保存可以自己部署，把 DATA_DIR 指到持久目录。
```
