Features

录入一次，展示与检索都省心

从「一个链接」到「一个可检索的产品档案」，中间的脏活都交给自动抓取。

链接即录入

粘贴部署地址，自动读取网页标题、描述、站点图标与主题色，名称和简介不用手敲。

GitHub 联动

自动同步 Star、Fork、主要语言与最近提交时间。私有仓库在设置里填入个人 Token 即可读取。

三种视图

卡片看封面、列表看信息密度、表格做横向对比。分类、标签、状态三重筛选，搜索即时生效。

详情即预览

产品详情页内嵌线上站点，边看边核对。遇到禁止嵌入的站点，自动提示并提供一键跳转。

状态看板

已上线、内测中、开发中、已归档四种状态，配上精选标记，一眼看清每个项目的进度。

数据自持

所有数据落在单个 JSON 文件里，没有云服务依赖。随时导出、随时迁移，也可以直接版本管理。

Workflow

三步，从链接到档案

不需要写一行配置，添加产品的过程就是粘贴两个地址。

STEP 01

粘贴部署链接

填入线上可访问的地址，点击「自动抓取」，站点标题、简介与图标自动回填。

https://your-app.vercel.app
STEP 02

补上代码仓库

粘贴 GitHub 地址即可同步 Star、语言等信息；私有仓库先在设置里配置个人 Token。

github.com/owner/repo
STEP 03

分类与展示

打上分类、标签与技术栈，选择视图。之后任何时候都能搜索到它，也能一键分享详情页。

/product.html?id=p_xxxxxx
